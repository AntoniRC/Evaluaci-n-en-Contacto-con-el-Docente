# JUEGO DE PIEDRA PAPEL O TIJERA

## Integrantes
Antoni Ronquillo

## Objetivo del sistema
Desarrollar un juego interactivo en lenguaje Python que permita aplicar de forma práctica todos los conocimientos adquiridos durante el semestre: manejo de variables, entrada y salida de datos, conversión de tipos, estructuras condicionales, bucles y funciones. El sistema debe permitir jugar, llevar un registro de puntos y mostrar información al usuario.

## Descripción de funcionalidades
- El programa muestra un menú con 4 opciones: Jugar, Ver marcador, Reiniciar marcador y Salir.
- Permite al jugador elegir entre Piedra, Papel o Tijera.
- La computadora elige su jugada de forma aleatoria.
- Compara las jugadas y determina automáticamente quién gana.
- Lleva el marcador de victorias, derrotas y empates.
- Valida que lo que escribe el usuario sea correcto y muestra mensajes de error.
- Permite consultar el marcador y reiniciarlo a cero.
- El código está organizado en funciones para mayor claridad.
